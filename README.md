# 向前冲 · Spring Run

竖屏跑酷小游戏：自动向前跑，跳过 / 蹲过障碍，吃道具升级，越跑越快。
纯静态 HTML5，无依赖、无构建、无外部资源 —— 打开 `index.html` 就能玩。

线上：<https://serenkyy.github.io/spring-run/>

---

## 怎么玩

| 操作 | 手机上 | 电脑上 |
| --- | --- | --- |
| **跳** | 点屏幕任意处（按住跳更高） | `空格` / `↑` / `W` |
| **蹲** | 按住右下角「蹲」，或向下滑 | `↓` / `S` |
| 重开 | 结束时点屏幕 | `回车` |
| 静音 | 右上角喇叭 | `M` |

- **3 颗心**：撞一下掉一颗 + 1.4 秒无敌；每 3 级回一颗（上限 3）。
- **道具**：♪ 音符 +25 XP，🍜 牛肉面 +40 XP 并回一颗心，♥ 爱心 = 一次护盾。
- **俄语单词**：按顺序捡字母拼出当前单词，集齐弹出单词卡（俄语 + 中文，共 14 个词），额外 +150 XP。
- **分数** = 距离（米）+ 道具加成，最高分存在 localStorage。

### 关卡

1→2 级需要 120 XP，之后每级 +75。升级会提速（30 → 68 单位/秒）、给 1.5 秒无敌、回心，并弹一句加油。
关卡名字是彩蛋：樱花起跑、钢琴小径、牛肉面街、镜头之下、俄语课堂……

## 本地运行

```bash
npx serve .          # 或者直接双击 index.html
```

装到手机主屏：iPhone Safari 打开链接 → 分享 → **添加到主屏幕**，之后点图标就是全屏、无地址栏，也能离线玩。

## 打包成单文件

```bash
node tools/build.mjs
```

生成一个自包含的单文件版（样式、脚本、图标全部内联，约 110 KB），发微信、发邮件都能直接打开。

## 测试

```bash
node --test test/core.test.mjs   # 逻辑：物理、碰撞、升级、存档不变量（18 项，很快）
node tools/verify.mjs            # 真浏览器端到端 + 截图（63 项，需要 tools/ 里装过 playwright）
```

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面外壳、样式、HUD、开始/结束界面 |
| `core.js` | 纯游戏逻辑：物理、生成、碰撞、升级、文案（Node 里也能跑） |
| `game.js` | 渲染（全部代码绘制，无图片）、触控、WebAudio 音效与钢琴背景音乐、存档 |
| `manifest.webmanifest` | PWA 清单，让「添加到主屏幕」像个 App |
| `icon-*.png` | 图标（`tools/make-icons.mjs` 生成，纯代码绘制） |
| `test/core.test.mjs` | 逻辑测试 |
| `tools/verify.mjs` | 真浏览器端到端验证 + 截图 |
| `tools/build.mjs` | 打包单文件版 |
| `DESIGN.md` | 设计说明 |

## 想改点什么

- **鼓励语**：`core.js` 里的 `MESSAGES`（升级 / 撞击 / 里程碑 / 结束各一组）。
- **俄语单词**：`core.js` 里的 `WORDS`，加一行 `{ ru: '...', zh: '...' }` 就行。
- **关卡名字**：`core.js` 里的 `LEVEL_TITLES`。
- **配色**：`core.js` 里的 `PALETTE` 和 `SKY_MOODS`。
- **难度**：`core.js` 里的 `TUNE`（速度、跳跃、血量、升级曲线）。
